# Веб-сервер 

Проект представляет собой локальный веб-сервер.

## Что делает этот проект :
* Отображает страницы - динамически загружает  HTML-файл `contacts` из папки `templates`.
* Поддерживает Bootstrap - стили и скрипты подключены локально через статическую папку `static/` для работы без интернета.
* Принимает POST-запросы - обрабатывает отправку данных из веб-форм и выводит полученные значения в консоль сервера.
* Обрабатывает ошибки - возвращает  оформленные страницы для ошибок 404 (Страница не найдена) и 500 (Внутренняя ошибка).
* Структура - настроен файл `.gitignore`, а чтение файлов на сервере происходит через контекстный менеджер `with`.

## Инструкция по запуску
```
python server.py
```
После этого проект будет доступен в браузере по адресу: `http://localhost:8080/`
